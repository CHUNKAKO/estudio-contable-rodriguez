ESTUDIO RODRIGUEZ - WEB V4.2 - AGENDA FISCAL

Se incorporó una sección Agenda Fiscal con filtros ARCA y ARBA.
Fuentes oficiales usadas para el snapshot: ARCA Agenda/Vencimientos y ARBA Vencimientos 2026.

IMPORTANTE: esta versión estática contiene un snapshot de datos oficiales verificados al 26/10/2026.
SICORE y Cargas Sociales se muestran con acceso a la agenda oficial cuando no se dispone de una fecha inequívoca en la portada pública consultada, para evitar publicar fechas no verificadas.

Para actualización 100% automática en Internet hace falta publicar la web con un pequeño backend/tarea programada que consulte las fuentes oficiales y regenere los datos. No es fiable hacer scraping directo desde el navegador por restricciones CORS y posibles cambios de estructura de los sitios oficiales.
